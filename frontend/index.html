What is FAHAM?

Every scary letter becomes a 60-second lesson.

How a letter flows through FAHAM. The orchestrator is a planner that decides which tool to call next, keeps a reasoning trace, and stops at a human-approval gate before any outward action.

Request lifecycle

POST /api/analyze
  1. Capture — camera / PDF upload in the PWA; image never leaves memory unredacted.
  2. Redact — IC, phone, account and address masked before any model sees the text.
  3. Plan — orchestrator builds a plan: classify → extract → verify → explain → teach → route → act.
  4. Tool calls — each step calls a typed tool; results are added to the agent state.
  5. Ground — procedures retrieved from the official source registry, cited with timestamp + confidence.
  6. Teach — lesson card + glossary terms written to the user's local profile.
  7. Approve — drafts, reminders and messages wait for the user's explicit approval.
  8. Discard — letter content is dropped after the session; only learned terms remain.
